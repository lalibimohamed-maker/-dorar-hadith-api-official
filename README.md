# موسوعة دين الله API — Deen Allah Encyclopedia API

منصة API متعددة اللغات للبحث المنظم في القرآن والحديث والتفسير والسيرة والفقه والعقيدة وكتب العلماء ومصادر تعليم القرآن، مع إسناد كل معلومة إلى مصدرها وعدم خلط صحة الرواية بوجودها في كتاب.

## الهوية

- الاسم العربي: **موسوعة دين الله**
- الاسم الإنجليزي: **Deen Allah Encyclopedia**
- اسم واجهة البرمجة: **Deen Allah API**
- الدرر السنية: مصدر رسمي للحديث داخل الموسوعة، وليست اسم الموسوعة.

## مبادئ أساسية

- النص القرآني الأصلي لا يُستبدل بالترجمة.
- الترجمة تُعرض منفصلة مع نسبة مصدرها.
- صحة الحديث أو الرواية تُقيّم مستقلة عن مجرد وجودها في كتاب.
- كتب السيرة والتاريخ لا تُعامل تلقائياً على أن كل ما فيها صحيح.
- كل مصدر خارجي يُنسب إلى صاحبه، ولا يُعاد نشر محتواه المحمي دون ترخيص.
- لغة السؤال لها الأولوية، ثم لغة الإعدادات، ثم العربية كافتراضي.
- قائمة اللغات قابلة للتوسع مستقبلاً.
- الفتوى تُنسب إلى العالم ومصدرها ولا تُقدَّم على أنها فتوى صادرة عن الموسوعة.
- حاسبة الفرائض أداة تعليمية؛ المسائل المركبة أو المختلف فيها تُعلَّم للمراجعة العلمية ولا يُسمح بالتخمين الصامت.

## الفقه المقارن والفتاوى

أضيف إطار بحث فقهي مقارن في `config/fiqh-research-framework.json` و`src/fiqh-research.js`، ويُستخدم لعرض المسألة بطريقة بحثية منظمة:

1. تعريف المسألة والوقائع والافتراضات.
2. الآيات المتعلقة بها.
3. الأحاديث مع بيان درجتها مستقلاً.
4. أقوال الصحابة والسلف عند الحاجة.
5. قول الحنفية والمالكية والشافعية والحنابلة كلٌّ في قسم مستقل.
6. الأقوال السنية الأخرى عند وجودها.
7. مناقشة الأدلة وسبب اختلاف العلماء.
8. عرض الترجيح فقط إذا كان مدعوماً بأدلة ومراجع موثقة؛ وإلا تُعرض المسألة على أنها غير محسومة آلياً وتحتاج مراجعة عالم.
9. إظهار المصادر والمؤلفين ومواضع الإحالة.

ويشمل سجل المنهج والبحث علماء وأئمة من بينهم: ابن تيمية، ابن القيم، ابن عبد البر، الخطيب البغدادي، ابن حزم، ابن عاشور، إضافة إلى مصادر الفتاوى المعاصرة المسجلة في الموسوعة. إدراج العالم في الفهرس لا يعني أن كل قول منسوب إليه قد تم التحقق منه؛ كل نسبة لها مسار تحقق مستقل.

### نقاط API الجديدة

- `GET /fiqh` — إطار البحث الفقهي والمذاهب والعلماء.
- `GET /fiqh/research?q=...` — البحث في العلماء وكتب الفقه والفتاوى المفهرسة.
- `GET /fiqh/template?q=...&madhhab=...` — إنشاء قالب بحث مقارن للمسألة، مع فصل المذاهب والأدلة والترجيح.

## المجالات

القرآن، التفسير، الحديث والتخريج، السيرة النبوية، الشمائل، العقيدة، أركان الإسلام، أركان الإيمان، الفقه وأصول الفقه، الفتاوى، الميراث والفرائض والوصايا، مقاصد الشريعة والكليات الخمس، كتب العلماء، والمواد التعليمية مثل أكاديمية القرآن والتجويد.

## الفرائض والميراث

يوفر `src/inheritance-calculator.js` نواة حاسبة فرائض للحالات السنية الشائعة، مع:

- خصم الديون والوصية المدخلة قبل التوزيع.
- أصحاب الفروض والعصبة في الحالات المدعومة.
- العَول مع إظهار عامل العول.
- الرَّد في الصورة البسيطة مع تنبيه إلى اختلاف بعض تفاصيله.
- أصل/مقام مشترك ومعلومات التصحيح عند الحاجة.
- اختيار سياق أحد المذاهب الأربعة.
- تحذيرات صريحة للجد والجدات وأولاد الابن وبعض صور الإخوة والمسائل المركبة بدلاً من اختلاق نتيجة.
- إحالات إلى القرآن وكتب الفرائض والمصادر الببليوغرافية المسجلة.

هذه الحاسبة ليست فتوى ولا بديلاً عن العالم أو جهة الإفتاء أو المتطلبات القانونية المحلية.
