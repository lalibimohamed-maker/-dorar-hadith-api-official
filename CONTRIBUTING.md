# Contributing to Dinullah Encyclopedia

Thank you for contributing to the open-source engineering layer of موسوعة دينُ الله.

## Scope

Contributions may improve source adapters, Quran/hadith/tafsir APIs, provenance, rights and evidence tracking, entity resolution, search, multilingual retrieval, PDF/DOCX acquisition, reproducible datasets, SDKs, tests and documentation.

## Scholarly boundary

Do not write raw acquisition/API output directly into the curated Corpus. New material must preserve source, edition, provenance, rights and verification metadata.

Do not add AI-generated Quran translations or represent generated text as a primary religious source.

## Content and rights

A source being discoverable does not imply redistribution permission. Unknown or review-required rights must remain gated from public redistribution.

## Code

Use Node.js for orchestration/integration where appropriate and Python for specialized document/data processing. Keep transformations reproducible and covered by tests.

## Pull requests

Describe what changed, the source or schema affected, rights/provenance implications, tests performed, and whether public releases or the curated Corpus are affected.

Small, reversible commits are preferred.
