# Code of Conduct

We are committed to a respectful, evidence-oriented and collaborative project.

Participants must treat contributors and researchers respectfully, distinguish evidence from interpretation, attribute scholarly claims to identifiable sources, avoid harassment and personal attacks, and report security or privacy issues privately when appropriate.

Disagreements about scholarly interpretation should be documented with sources rather than personal attacks.

This code governs project participation; it does not require agreement on theological or jurisprudential questions.
