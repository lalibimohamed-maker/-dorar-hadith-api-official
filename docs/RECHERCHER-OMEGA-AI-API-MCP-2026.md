# Rechercher Ω — AI API + MCP boundary (2026)

This is the machine-facing boundary of Din Allah Encyclopedia.

## Free-first rule
No paid API is required. The gateway and MCP server are dependency-free Node runtimes and can point at the existing encyclopedia API. Model binaries remain separate Release assets and are never committed to Git or the scholarly Corpus.

## API
Run: `npm run ai-gateway`
Default port: `8790`.
Read-only agent endpoints:
- `GET /api/v1/agents/health`
- `GET /api/v1/agents/search?q=...`
- `GET /api/v1/agents/concept?term=...`
- `GET /api/v1/agents/quran?verse=...`
- `GET /api/v1/agents/source/:id`
The gateway applies bounded inputs, machine-readable error codes, a token-bucket rate limit, and an explicit evidence envelope. It does not expose a Corpus-write operation.

## MCP
Run: `npm run mcp`
Default endpoint: `POST /mcp`, port `8787`.
The implementation targets MCP `2026-07-28` and accepts the legacy `2025-11-25` revision for compatibility. The current MCP revision is stateless: requests carry protocol metadata per request; protocol-level sessions are not required.
Tools:
- `deen_search`
- `deen_concept`
- `deen_quran_ayah`
- `deen_source`
- `deen_health`
No tool can write to Corpus, alter canonical Quran text, replace provenance, or make a rights decision.

## Evidence boundary
Every downstream evidence item must retain source, document identity, provenance, rights state, verification state and SHA-256. Semantic similarity or model confidence never overrides a hard evidence rejection.
Canonical Quran text is retrieved and verified; it is not generated by the language model.

## Release boundary
Runtime software and model weights are stored as Release assets with immutable upstream revisions and SHA-256 manifests. Large files are split below the GitHub Release asset limit and reconstructed from their manifest. Restricted, non-commercial, gated, or rights-unknown weights remain blocked/draft/private according to their rights state.

## Corpus boundary
Generated text, images, audio and video are derived/presentation artifacts. They never become scholarly evidence merely because an AI model generated them.
