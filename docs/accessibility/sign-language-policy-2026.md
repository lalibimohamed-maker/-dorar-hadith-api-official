# طبقة لغة الإشارة — سياسة الإتاحة 2026

تهدف هذه الطبقة إلى جعل موسوعة دين الله قابلة للاستعمال من الصم وضعاف السمع، مع أولوية للعربية ولغة الإشارة الجزائرية حيث تتوفر موارد قابلة للتحقق.

## المبادئ

- لغة الإشارة لغة مستقلة وليست تحويلًا حرفيًا للغة المنطوقة.
- لا نفترض وجود لغة إشارة عالمية واحدة.
- لكل لغة/منطقة/لهجة سجل lexicon وgrammar وprovenance مستقل.
- لا يُنشر تعبير على أنه صحيح دون تحقق من المصدر ومراجعة من متحدثين أصليين أو مختصين عند الإمكان.
- لا نُعدّل النص الإسلامي أو العلمي الأصلي عند إنتاج ترجمة إشارية.
- عند انخفاض الثقة، نعرض النص أو نطلب إعادة الإشارة بدل اختلاق معنى.

## المساران

### Sign-to-Text / Sign-to-Speech

الكاميرا → كشف اليدين والوجه والجسم → تتبع الحركة → تعرف التسلسل → لغة الإشارة → نص → صوت اختياري.

### Text-to-Sign

النص → تحديد اللغة/المنطقة → تحليل لغوي → lexicon/sign mapping → HamNoSys/SiGML عند التوفر → Avatar أو فيديو أصلي.

## الموارد المفتوحة

### ArSLr

مرجع بحثي رئيسي للتعرف على لغة الإشارة العربية. مستودعه مرخص MIT ويضم التعرف على 32 حرفًا عربيًا وكلمات ديناميكية؛ يذكر README دقة اختبار 95% للحروف و97% للكلمات الديناميكية. هذه الأرقام خاصة بتجارب المشروع ولا تعني دقة إنتاجية عامة للموسوعة.

### MediaPipe

طبقة التتبع البصري المفتوحة تحت Apache-2.0، لتحديد اليدين والهيئة والحركة ودعم المعالجة على الجهاز حيث يناسب ذلك.

### ARSLW

مورد بيانات عربي مرخص MIT، لكنه يخضع لتدقيق جودة/provenance وموافقة استخدام الوسائط قبل إدخاله في أي مسار إنتاجي.

### Algerian Sign Language Avatar

مرجع مهم للغة الإشارة الجزائرية وللتوليد عبر 3D avatar وHamNoSys/SiGML/CWASA، لكنه يحمل CC BY-NC-4.0؛ لذلك يُستخدم في مسار تجريبي/غير تجاري فقط، ولا نفترض حق إعادة التوزيع التجاري أو إعادة استخدام كل الأصول دون تدقيق منفصل.

## الجودة

يجب تقييم:

- دقة الحروف والكلمات والجمل المستمرة.
- اختلافات الإشارة بين المستخدمين.
- الوضعية والإضاءة وزاوية الكاميرا.
- الحركات غير اليدوية، الوجه والفم والجسم.
- latency على الهاتف.
- استهلاك البطارية والذاكرة.
- نسبة false recognition.
- قبول متحدثي لغة الإشارة.
- سلامة provenance والترخيص لكل مجموعة بيانات أو حركة.

## الخصوصية

الكاميرا والصوت لا يُرفعان افتراضيًا. المعالجة المحلية مفضلة، مع إذن صريح قبل أي خدمة خارجية. الفيديو الخام لا يدخل Corpus ولا يصبح مصدرًا علميًا.

## الإعجاز والمحتوى الديني

الترجمة الإشارية هي طبقة عرض وإتاحة. لا تُعد مصدرًا أصليًا، ولا تُستخدم لإعادة تفسير النص الشرعي. يبقى النص العربي الأصلي والترجمة المرجعية والإسناد منفصلين وقابلين للتتبع.

## حالة النشر

`discovered → source_verified → rights_verified → signer_review → scholarly_review → published`

وأي مورد مجهول الحقوق أو غير موثوق يدخل `quarantine` ولا يُنشر تلقائيًا.
