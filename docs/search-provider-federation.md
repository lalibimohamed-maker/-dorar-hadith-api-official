# شبكة مزودي البحث متعددة الطبقات

المستخدم يرى محركًا واحدًا، بينما تعمل داخليًا مجموعة مزودين بالتوازي. الشبكة ليست محصورة في Google/Bing/Yandex؛ يمكن إضافة Brave وMojeek وDuckDuckGo ومزودين آخرين عبر تكامل قانوني ورسمي.

## التوجيه حسب المجال

- القرآن والتفسير: مصادر القرآن/التفسير المتخصصة أولًا، ثم الويب.
- الحديث: المصادر الحديثية المتخصصة أولًا، ثم الويب.
- الكتب: موصلات الكتب والمكتبات أولًا، ثم الويب.
- الفتاوى: مصادر الفتاوى المعتمدة أولًا، ثم الويب.
- الاستعلامات العامة داخل مجال الموسوعة: مزودو الويب المتعددون.

نتائج مزودي البحث الخارجيين هي نتائج اكتشاف فقط. لا تصبح مصدرًا معتمدًا ولا تدخل Corpus أو Digital Master إلا بعد Provenance وRights وValidation.

لا يجوز تنفيذ scraping غير مصرح به أو تجاوز حدود/شروط أي مزود. التكامل يجب أن يستخدم API أو وسيلة يجيزها المزود وشروطه.
