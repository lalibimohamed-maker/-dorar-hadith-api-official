# Zero-Cost Integration Status

The universal free-distribution work is staged on a review branch and must enter the protected encyclopedia branch through pull-request review.

The implementation deliberately does not claim unlimited free hosting. Provider quotas, terms, and rights gates are part of the design.

The five launch priority locales are Arabic, English, Chinese, Spanish, and Russian. The PWA/web path remains the universal baseline; official app stores remain secondary channels because store distribution can require paid developer membership.

Internet Archive is treated as an external storage/distribution candidate rather than a source of scholarly authority or a native GitHub identity-linked account. Credentials remain outside Git and every upload is rights/provenance gated.
