# Rechercher Learning Intelligence Engine v3 — Global Research 2026

## Implementation status

The v3 layer is now implemented as a graph-grounded learning-intelligence core above acquisition.

### P0 core

- Knowledge Graph and Evidence Graph schemas with stable identifiers.
- Provenance-aware graph relations and explicit candidate/verified/disputed status.
- Directional prerequisite graph with confidence-weighted gap routing.
- Learner mastery graph with separate retrieval, explanation, application, discrimination, transfer, source-navigation, and retention dimensions.
- Confidence calibration state separated from correctness.
- Privacy-minimal multimodal performance profile.
- Non-blocking acquisition invariant.

### P1 core

- Misconception hypotheses with typed failure diagnosis.
- Source-grounded learning-object lifecycle and source-change invalidation.
- Versioned instructional method registry.
- Verified-evidence transfer task contract.
- Progressive explanation contract.
- Immediate/delayed/transfer evaluation records.

### Evaluation primitives

The engine can record method outcomes, create ablation plans, and summarize observed immediate, delayed, transfer, calibration, and time outcomes. It does not automatically declare a universal best method or promote an intervention without evidence.

### LLM boundary

LLM/AI output is constrained to assistance, explanation, generation, dialogue, and candidate graph discovery under source/evidence grounding. Generated educational output is not canonical corpus content and cannot write canonical religious material through this layer.

### Religious integrity

The engine distinguishes memory failure, terminology confusion, source-attribution error, contextual misunderstanding, scholarly disagreement, and conceptual-misconception hypotheses. A graph relation is an indexed claim with provenance/status, not an automatic declaration of truth.

### Acquisition independence

Learning, graph, evaluation, and multimodal failures must never block PDF discovery, acquisition, preservation, validation, normalization, rights processing, or provenance recording. The v3 API exposes an explicit acquisition-independent invariant.

### Remaining future work

Dynamic graph evolution, production persistence, large-scale trained knowledge tracing, validated recitation evaluators, offline graph synchronization, scholar workflow automation, and longitudinal method-evaluation infrastructure remain separate increments.
