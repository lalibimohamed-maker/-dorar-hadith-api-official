# موصلات مصادر الكتب

موصل المصدر ليس تصريحًا بإعادة النشر، ولا يقوم بجلب النص تلقائيًا. وظيفته تحديد ما إذا كان المصدر مؤهلًا للدخول إلى طبقة الجلب المستقبلية.

قبل السماح بالجلب يجب أن تتوفر:

1. هوية المصدر ورابطه.
2. provenance موثق مع وقت التحقق.
3. حالة حقوق تسمح بإعادة التوزيع: `redistributable` أو `licensed` أو `public-domain`.
4. نتيجة validation مساوية لـ`valid`.

أي نقص أو غموض يؤدي إلى `blocked` (fail-closed).

هذه الطبقة متعمدة في كونها **contract فقط**: لا HTTP fetching، ولا OCR، ولا تخزين، ولا فهرسة، ولا إدخال نصوص. هذه العمليات ستأتي لاحقًا وتُجبر على المرور بهذا العقد وبسياسة مخزن الكتب.
