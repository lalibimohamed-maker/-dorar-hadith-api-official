# Zero-Cost-First: Final Engineering Position

This project makes a durable commitment to free user access, while refusing to make false claims about unlimited third-party services.

## What is guaranteed by architecture

- No paid subscription is required for core web/PWA reading and search.
- No paid API key is required for core reading/search.
- Core approved downloadable content remains free when redistribution rights permit.
- Phase-one localization is Arabic, English, Chinese, Spanish and Russian; the architecture can grow to additional locales.
- Offline/local computation is a first-class path.
- Critical assets use provenance, checksums and independent fallback paths.
- No single provider is the sole source of availability.

## What is not promised

- No provider is described as unlimited or permanently free without a current source supporting that claim.
- App-store publication is not assumed to be free; it is optional compared with the web/PWA route.
- Internet Archive is not treated as a perpetual or unlimited guarantee; its current terms and item eligibility must be checked for every integration.
- P2P is not treated as universally available or reliable on every browser/device.

## Mission

Poverty must not prevent access to the core encyclopedia. The system therefore prefers free/open/self-hosted technology, graceful degradation, offline bundles and community-supported distribution over mandatory paid infrastructure.
