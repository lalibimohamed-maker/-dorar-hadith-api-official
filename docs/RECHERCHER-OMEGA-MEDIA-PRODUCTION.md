# Rechercher Omega — Media Production

The media layer is now an executable planning boundary rather than a model list.

Research case -> reviewed script -> storyboard -> permitted assets -> generation/editing -> voice -> subtitles -> FFmpeg composition -> rights/provenance -> Council -> publication.

Local ComfyUI uses COMFYUI_URL and requires an explicit workflow. Local FFmpeg is the deterministic composition/transcoding lane. Kaggle is a remote GPU lane requiring an explicit kernel and command. Hugging Face remains optional under the free-first quota gate.

HunyuanVideo-1.5 exposes text-to-video and image-to-video pipelines; LTX-2 is an audio-video foundation model with synchronized audio/video and local execution support. Generated media remains explanatory output, not evidence, and no media runtime can write directly to Corpus.
