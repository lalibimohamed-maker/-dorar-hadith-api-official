# موسوعة دين الله — مخطط اكتمال المنظومة 2026

هذا العقد يجمع قواعد الاكتمال المعماري في طبقة حوكمة مستقلة فوق الـCorpus.

## المبدأ الحاكم

كل محرك تقني أو آلي أو واجهي أو تحليلي يعمل فوق المحتوى العلمي المعتمد. لا توجد آلية لاستبدال المصدر المعتمد بصمت أو تحويل نتيجة آلية إلى نص أصلي.

## الاكتشاف والاعتماد

نتيجة الاكتشاف تبدأ كـ`candidate`. لا تصبح قابلة للاعتماد إلا بعد اكتمال المصدر، provenance، الحقوق، التحقق المستقل، والمراجعة الملائمة. الاكتشاف وحده ليس دليلًا علميًا.

## تعدد المحركات

كل قدرة تتطلب حدًا أدنى محركين مستقلين، وثلاثة كمستوى مفضل. اختلاف النتائج ينتج حالة تعارض للمراجعة ولا يتحول إلى تصويت آلي.

## فصل أنواع الحقيقة

يُميّز العقد بين النص الأصلي، بيانات المصدر، الحكم المنقول، شرح العالم، التحليل والاستنباط، الترجمة، والمخرج التعليمي. لكل طبقة lineage وحالة ومصدر مستقلان عند الحاجة.

## Lineage والتاريخ

OCR والترجمة والنسخ المشتقة تحمل معرفات للآباء والتحويل. السحب أو الاستبدال أو التصحيح يسجل كحدث تاريخي ولا يمحو السجل السابق.

## المراجعة العامة

المساهمات العامة تبدأ في `quarantine`. لا تملك تعديل المصدر الأصلي مباشرة، ولا تصبح مقبولة بلا مراجع.

## المعايير الخارجية

DCMI، IIIF، W3C Web Annotation، RO-Crate، PREMIS، WCAG 2.2 AA، وW3C Trace Context تستعمل للتنسيق والتبادل والوصف والحفظ والوصولية والمراقبة، لا كمصادر علمية.

## الاستدامة والحقوق

إتاحة المادة مجانًا لا تعني أنها Public Domain. إعادة النشر والتنزيل لا يفتحان إلا عند وجود حالة حقوق تسمح بذلك. لكل أصل حالة حقوق مستقلة.

## حدود هذه الطبقة

هذا التنفيذ يثبت العقود والبوابات والاختبارات. لا يدّعي وجود قاعدة بشرية أو قاعدة بيانات تشغيلية أو بنية أجهزة/نسخ احتياطي جاهزة ما لم تُثبتها طبقة تشغيل منفصلة. ولا تدخل هذه الطبقة في مسار اكتساب Rechercher أو تعديل Corpus.
