# Rechercher Learning Intelligence v4

V4 adds four architectural layers: session versus long-term learner memory, a bounded feedback-loop buffer, an explicit cross-domain transfer graph, and a pedagogical safety/alignment layer.

The learning system is hybrid and evidence-grounded: governed corpus and source constraints remain fixed, while sequencing, practice, explanations and modality selection adapt to learner state. Generative tutoring is subordinate to verified evidence.

Session memory is ephemeral working context. Long-term memory stores summarized mastery, calibration, misconceptions, modality performance and transfer history across weeks or months.

The feedback buffer captures pause, hesitation, revision, hint request, answer attempt, confidence change, navigation and completion signals. Signals feed diagnosis and calibration immediately but are not automatically persisted as a raw diary.

The cross-domain graph explicitly represents source skill, target skill, relation, evidence and confidence. Transfer is evaluated separately from source-domain mastery.

Pedagogical safety requires scaffold-first behavior during struggle, progressive disclosure, preservation of learner agency, source-grounded religious explanations, rights awareness and no biometric inference by default.

PDF Acquisition remains upstream and independent: discovery, acquisition, validation, inspection, OCR/extraction, integrity, normalization, manifest and storage. Learning Intelligence cannot block acquisition.
