# Global cross-device display federation

هذه الطبقة توحّد مشاركة شاشة الموسوعة على التلفاز، الحاسوب، البروجيكتور، الهاتف، اللوحي والأجهزة المتوافقة، مع اختيار المسار حسب القدرة الفعلية للجهاز والنقل.

## البروتوكولات والمحركات

تشمل طبقة المرشحين Miracast/MiracleCast، AirPlay/UxPlay، Cast adapters، Screen Capture/WebRTC، scrcpy وSunshine/Moonlight. لا يعني التسجيل أن البرنامج مثبت أو أن الجهاز يدعم البروتوكول؛ لذلك يظل كل محرك في حالة مرشح إلى أن يثبت وجوده وقدرته.

`getDisplayMedia()` يتطلب موافقة المستخدم في المتصفح، وتوضح وثائق MDN أن الميزة ليست متاحة في جميع المتصفحات. لذا لا نعتمد عليها كحل وحيد لجميع الأجهزة. citeturn853171search0turn853171search3

## الدقة

سياسة الدقة مفتوحة: `native / 4K / 8K / 10K / 12K / 16K / 24K / future`.

هذه تسميات لقدرات أو أصول فعلية وليست وعدًا بأن كل جهاز يمكنه عرضها. التفاوض لا يتجاوز أصغر قدرة مثبتة بين المصدر والوجهة. ولا يجوز وصف ناتج معاد البناء بأنه Native.

## الأمان

تتطلب جلسة المشاركة موافقة صريحة، وتفضّل الاكتشاف المحلي، ولا يتم كشف الشاشة على الإنترنت تلقائيًا. لا يوجد تثبيت أو تفعيل صامت لمحركات ذات صلاحيات حساسة.

## Free-first

لا يوجد API مدفوع أو اشتراك مطلوب في النواة. المحولات التي تعتمد على منصات خارجية تبقى اختيارية.

## نطاق الموسوعة

هذه طبقة عرض وبنية تحتية فقط، ولا تعدّل الـCorpus ولا المحتوى العلمي ولا تمنح نتائج البحث الخارجية سلطة علمية.
