# موسوعة دين الله — Engineering Tooling Watchlist 2026

هذه القائمة تحول الروابط الهندسية المكتشفة إلى طبقات واضحة بدل إدخال الأدوات عشوائيًا في المنتج.

## ما دخل فعليًا

### Driver.js
يُستخدم كتحسين اختياري لجولات الواجهة والإرشاد السياقي. الإصدار مثبت، وفشل تحميله لا يمنع تشغيل الموقع؛ يوجد fallback محلي.

### Lucide
يُستخدم للأيقونات في طبقة الواجهة فقط. الإصدارات الخارجية مثبتة، ونحافظ على إشعارات الترخيص اللازمة.

### Aura Gradients
نأخذ فكرة التدرجات الهادئة فقط. لا يعتمد الموقع على طلب runtime من موقع Aura.

## ما نستفيد منه هندسيًا

ECC: منهج agent harness من البحث والتخطيط والاختبار والمراجعة والتحقق والذاكرة.

Gemini CLI: أداة تطوير وتجريب MCP، وليست مزود الاستدلال الأساسي للهُدى.

Gitingest: تحويل المستودع إلى سياق منظم للمراجعة والتحليل.

GitDiagram: توثيق بصري للمعمارية.

WTFJS: مرجع لحالات JavaScript الحدّية التي يمكن تحويلها إلى اختبارات regression.

Flexbox Labs: مرجع للتخطيط المتجاوب وRTL.

## ما يبقى رادار اكتشاف

GitHub Topics الخاصة بـMCP وagent-harness وagent-framework وLLM وغيرها تُستخدم لاكتشاف مشاريع جديدة فقط. لا يصبح repository مرشحًا للإدماج بسبب وجوده في Topic وحدها.

## الحدود

- لا تغيير لـCorpus.
- لا تحويل أدوات التطوير إلى اعتماد runtime لمجرد شعبيتها.
- لا API أو model registry يصبح مصدر ثقة دينيًا دون provenance مستقل.
- أي أصل مرئي أو كود من طرف ثالث يخضع لمراجعة الترخيص قبل إعادة توزيعه.
