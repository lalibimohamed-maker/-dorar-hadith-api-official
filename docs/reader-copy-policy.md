# سياسة القراءة ونسخ النص

حقوق القراءة ليست هي نفسها حقوق إعادة التوزيع.

## القراءة

يمكن إتاحة القراءة عندما تكون حالة الحقوق قابلة لذلك، أو عندما يصرح المصدر بالقراءة.

## Copy Text

زر `Copy Text` مستقل عن صلاحية تنزيل الكتاب كاملًا. لا يُفعّل إلا إذا كانت سياسة المصدر والحقوق تسمح بالنسخ النصي.

## إعادة التوزيع

لا يُسمح بتصدير أو تنزيل نسخة كاملة إلا للحالات المسموح بها: `redistributable` أو `licensed` أو `public-domain`.

الحالات `restricted` أو الحقوق غير الواضحة لا تتحول تلقائيًا إلى إذن بالنسخ أو إعادة التوزيع.

بهذا يستطيع القارئ استخدام واجهة قراءة غنية دون تحويل إتاحة القراءة إلى ترخيص لإعادة نشر الكتاب كاملًا.
