# Global Multilingual Knowledge Network 2026

تتعامل الموسوعة مع اللغة كطبقة عرض واسترجاع فوق رسم معرفة واحد مشترك.

## المسار

`User language -> intent detection -> multilingual retrieval -> source verification -> provenance graph -> response in user language`.

## فصل اللغات

لغة الواجهة، لغة الاستعلام، لغة الإجابة، ولغة المصدر حقول مستقلة. يمكن اختيار لغة الرد من لغة المستخدم حتى عندما لا تكون لغة واجهة مكتملة التسجيل.

## المصدر والترجمة

النص الديني الأصلي يبقى مستقلاً ولا تستبدله الترجمة. الترجمة المعيّنة تحمل المترجم ومصدرها وحالتها؛ المخرجات الآلية تبقى `machine-draft`.

## الاسترجاع

الكيانات القانونية/المعرفية لها معرف canonical واحد، وتستعمل aliases متعددة اللغات للاسترجاع دون تغيير الهوية. الاستعلام المختلط اللغات يمكن أن يبحث عبر أكثر من لغة.

## Provenance

كل claim ديني مرتبط بسجل مصدر وprovenance. نقص الأدلة ينتج `insufficient-evidence` بدل اختراع معلومة أو رفع حالة الثقة.

## الوسائط

الفيديو والصوت والمقالات والصور وسائر الوسائط تعامل كمصادر وسائط، ولا تكتسب سلطة دينية افتراضيًا.

## الاتجاه

يضبط النظام RTL/LTR تلقائيًا حسب لغة العرض، مع بقاء لغة المصدر منفصلة عن لغة الإجابة.
