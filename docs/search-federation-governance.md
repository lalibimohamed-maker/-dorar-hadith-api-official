# شبكة حوكمة البحث المتوازي

محرك البحث الرئيسي هو الواجهة الوحيدة للمستخدم. خلفه توجد موصلات بحث متعددة تعمل بالتوازي لتسريع الاكتشاف وتوسيع التغطية.

## المسار

`User Query → Language Resolution → Main Search → Parallel Provider Jobs → Merge/Deduplicate → Rank/Validate → Answer`

## الحدود

- عدد موصلات البحث المتزامنة محدود بـ8 في الخطة الحالية.
- لكل عملية مهلة قصيرة ومحددة؛ لا ينتظر المحرك مصدرًا بطيئًا إلى ما لا نهاية.
- نتائج الموصلات هي مواد اكتشاف، وليست تلقائيًا مصادر معتمدة.
- Provenance وRights وValidation تبقى بوابة مستقلة قبل إدخال المحتوى أو تنزيله.
- لا يُكشف للمستخدم تعقيد الشبكة الداخلية؛ يحصل على نتيجة موحدة.
- يمكن للمحرك إعادة المحاولة أو استخدام cache عند تعطل موصل، دون تعطيل الاستجابة كلها.

الهدف هو تقليل زمن الاستجابة مع الحفاظ على الحوكمة: السرعة لا تتجاوز التحقق العلمي والحقوقي.
