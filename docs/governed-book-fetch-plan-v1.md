# جلب الكتب المحكوم — v1\n\nهذه الطبقة تخطط للجلب فقط ولا تنفذ HTTP fetching.\n\n## شروط الخطة\n\nلا تُنشأ خطة إلا بعد اجتياز موصل المصدر والتحقق من حالته، ووجود هوية المصدر والنسخة، وprovenance مكتمل ومتحقق، وحقوق تسمح بإعادة التوزيع، وvalidation ناجح، ورابط HTTPS صالح، ونوع محتوى مسموح، وحجم لا يتجاوز 25 MiB.\n\nأي نقص أو مخالفة ينتج blocked.\n\n## الحدود\n\nلا تقوم هذه الطبقة بالجلب أو التخزين أو parsing أو OCR أو فحص المحتوى. تنفيذ الجلب الفعلي يبقى في طبقة منفصلة، ولا يملك تجاوز بوابات المصدر والحقوق وprovenance والتحقق.\n
