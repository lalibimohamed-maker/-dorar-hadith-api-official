# منظومة أبواب الإيمان والتعظيم والاقتداء — Knowledge Mesh 2026

هذا العقد يجعل **أبواب الإيمان والتعظيم والاقتداء** جذرًا لشبكة معرفة مترابطة فوق الـCorpus، لا مجموعة صفحات فضائل منفصلة.

## الاعتماد

الحالات: `discovered -> corroborated -> scholarly-reviewed -> rights-cleared -> publishable`. لا يعتمد محرك واحد مادة علمية بمفرده؛ الحد الأدنى محركان مستقلان، وثلاثة مفضلة.

## فصل الحقيقة

القرآن، الحديث، شرح العالم، التحليل الموسوعي، والترجمة الآلية كيانات مستقلة. OCR والترجمة الآلية مشتقان، ولا يكتسبان سلطة النص الأصلي.

## القربات

كل قربة تسجل العائلة، الدليل، الحكم، الشروط والأركان والسنن والفضائل والمقاصد والأخطاء والآثار الإيمانية وصلتها بالإخلاص والمتابعة.

## الصحابة

سجل الصحابي يحمل الهوية والنسب والكنية وحالة الصحبة والأدلة والمواقف والروايات والصلة بالنبي ﷺ والأعمال والأقوال والأحداث والوفاة والمصادر. الخلاف في الصحبة يبقى صريحًا ولا يُحسم آليًا.

## الاستكشاف

الاكتشاف المستمر يضيف candidates فقط. الإدخال إلى المحتوى الموثوق يظل محكومًا بالت corroboration والمراجعة والحقوق.

## البطاقات

لا ينشئ Card Studio بطاقة من مصدر غير قابل للنشر. الإخراج متجهي أولًا، بصيغ SVG/PNG/WebP/PDF، ويحمل توقيع «موسوعة دين الله» ومعرفًا ثابتًا وبصمة قابلة لإعادة التوليد مع provenance والحقوق.

## اللغات

مسجل اللغات يحفظ اللغة والخط والمنطقة والاتجاه وحالة الترجمة. الترجمة الآلية = `machine-draft` ولا توصف كترجمة دينية معتمدة دون المراجعة المطلوبة. النص القرآني المعياري مستقل عن الترجمة.

## الحقوق

المادة المجانية ليست تلقائيًا Public Domain. الأصل المقيد لا يُنقل إلى مستودع قابل للتنزيل؛ يمكن الاحتفاظ بالفهرسة والرابط عند الحاجة.

## حدود

هذه طبقة معرفة وحوكمة فوق الـCorpus ولا تعيد كتابة المحتوى العلمي.
