# Rechercher — Global 133 × 48 Search Matrix

This branch consumes the same **133 languages × 48 Islamic knowledge domains = 6,384 cells** contract as PR #541.

The matrix is a System-Layer discovery/evidence queue. It does not write to the canonical Corpus. Domain 48 is the automatic catch-all for additional Islamic knowledge subjects, with automatic subject classification.

Rights remain item-level: discovery, API access, or the existence of a source does not by itself grant redistribution permission.
