# Rechercher — Global 133 × 48 Search Matrix

## Objective

Rechercher executes a deterministic evidence-driven matrix of **133 evidenced languages × 48 Islamic knowledge domains = 6,384 cells**.

Domains 1–47 are explicit scholarly subjects. Domain 48 is the automatic catch-all for additional Islamic knowledge subjects not yet represented in domains 1–47; newly discovered material is classified by subject.

## Governance

Discovery does not equal redistribution permission. Every resource remains subject to edition/resource identity, provenance, item-level rights, integrity/QC and governed storage.

The canonical Arabic Quran remains isolated from human translations and any machine-translated fallback. No translation or discovery lane may overwrite canonical Arabic source content.

## Evidence pipeline

`primary/institutional source → official API → digital corpus → structured web → scholarly dataset → translation metadata → provenance → rights → verification`

Missing evidence remains an explicit gap; the system must not fabricate a source or translation to fill a cell.

## Expansion

The 106-language figure is a minimum evidence target, not a hard cap. The 48-domain matrix is the current execution contract, with domain 48 absorbing otherwise-unclassified Islamic knowledge until subject classification is available.
