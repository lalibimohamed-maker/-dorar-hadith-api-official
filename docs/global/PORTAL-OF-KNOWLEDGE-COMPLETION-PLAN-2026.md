# بوابة العلم — خطة الإكمال التنفيذية 2026

هذه الوثيقة تحول المخطط المرجعي إلى خطة تنفيذ قابلة للتحقق، ولا تعتبر أي قدرة مكتملة لمجرد وجود وصف أو إعداد.

## المراحل

1. Registry: حصر الأقسام والوظائف والمحركات والمصادر والبنية التحتية وتصنيف حالتها.
2. Core: توحيد البحث، الأدلة، provenance، الحقوق، وإصدارات المحتوى.
3. Knowledge: ربط القرآن والحديث والتفسير والسيرة والعلماء والكتب وبقية corpus بالشبكة المعرفية.
4. Books: تشغيل OCR/restoration/consensus/review مع حفظ الأصل وإخراج PDF/DOCX/EPUB/PPTX حيث تسمح الحقوق.
5. Translation: تشغيل mesh متعدد المحركات والقواميس والـglossaries وquality gates وtranslation cache.
6. Media: تشغيل الصور والصوت والفيديو والتفريغ والمزامنة والبث وفق الحقوق.
7. User: PWA، البحث الصوتي، history/calendar، offline، study modes، الخرائط، المساجد، القبلة والمواقيت.
8. AI: إجابات مؤسَّسة على الأدلة مع citation/provenance، وكشف النسبة والتعارض وعدم التخمين.
9. Verification: unit + integration + E2E + security + rights + corpus-boundary + multilingual + performance + recovery.
10. Release: لا دمج نهائي ولا إعلان اكتمال قبل اجتياز كل بوابات الجاهزية.

## قواعد غير قابلة للتجاوز

- الأصل محفوظ ولا يُستبدل بالمشتق.
- لا تعديل صامت للـCorpus.
- لا تخمين يتحول إلى حقيقة.
- المصدر غير المتاح لا يُعلن باطلًا لمجرد HTTP 403.
- حقوق إعادة التوزيع شرط مستقل عن إمكانية التنزيل تقنيًا.
- الترجمة ليست بديلًا عن النص الأصلي.
- Free-first: لا اعتماد مدفوع لازم للقلب الأساسي.
- كل قدرة يجب أن تحمل دليل تنفيذ واختبار قبل تصنيفها IN_MAIN.
