# Zero-Cost Review Gate

Before any distribution artifact is published, verify:

- canonical content comes from the approved Corpus or approved derived layer;
- provenance is complete;
- rights permit the intended redistribution;
- checksum exists;
- locale is explicit;
- machine translation is labeled draft when not reviewed;
- the artifact has at least one fallback distribution path;
- no secret is present in repository content or generated artifact;
- provider quotas/terms have been checked;
- no paid dependency is mandatory for core access.
