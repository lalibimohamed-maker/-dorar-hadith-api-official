## Operational rules

1. No third-party binary or model weight is committed to Git.
2. Every runtime installation emits version and source information.
3. Unknown or restricted model licensing fails closed.
4. Paid APIs are adapters only and can never be a required core backend.
5. Canonical Quran Arabic text and canonical recitation are never generated by these engines.
6. Generated media never becomes scholarly evidence.
7. Installation and model caches belong to disposable/external runtime storage, not the Corpus.
8. Attribution/license notices must travel with redistributable delivery artifacts where required.

## Verification references

- FFmpeg's official legal page states that the main code is LGPL-2.1-or-later, with optional GPL components. 
- Blender's official license page states Blender is GPL and documents its third-party components.
- OpenAI Whisper's upstream repository states its code and model weights are MIT licensed.
- WhisperX upstream currently declares BSD-2-Clause.

This register is a governance record, not legal advice. Model cards and exact release licenses must be checked before redistributing weights.
