# Free Book Processing Group — 2026

## الهدف

هذا المسار هو طبقة مجانية أولًا لمعالجة الكتب الرقمية وغير الرقمية داخل موسوعة دين الله. لا يعتمد على اشتراك مدفوع أو API مدفوع، ويعمل محليًا قدر الإمكان.

## لماذا المجموعة وليست محركًا واحدًا؟

لا يُسمح لمحرك OCR منفرد بأن يصبح مرجعًا علميًا. بالنسبة للصفحات العربية العادية، نطلب عادةً نتيجتين مستقلتين على الأقل من PaddleOCR وTesseract و/أو Kraken. إذا اختلفت النتائج في منطقة مؤثرة، تُعزل الصفحة للمراجعة بدل اختيار نص بصمت.

## قاعدة الكتب

1. احفظ الأصل وSHA-256 قبل أي معالجة.
2. لا تعدّل Corpus الأصلي بسبب OCR أو التنظيف.
3. عالج الصفحة بصريًا مع أقل تدخل ممكن.
4. لا تستخدم إزالة الخلفية القوية تلقائيًا على كل الصفحات.
5. استخدم dewarping فقط عندما تتجاوز الصفحة بوابة الجودة.
6. افصل النص عن الخلفية عند الحاجة بدل تبييض الصفحة كاملة.
7. اكتشف موضع `……………………` على مستوى الصفحة.
8. غطِّ النقاط بدرجة الخلفية المحلية نفسها، ولا تمس الحروف المجاورة.
9. ضع الإجابة داخل موضع النقاط فقط.
10. قارن النسخة المشتقة بالأصل عبر visual diff؛ أي تغيّر خارج منطقة القناع غير المصرح به يفشل.
11. افحص PDF النهائي وبنيته وعدد الصفحات والأبعاد.
12. سجّل المحرك والإصدار والإعدادات والهاش وحالة التحقق.

## رقمي وغير رقمي

### PDF رقمي

نفحص طبقة النص أولًا. إذا كانت سليمة، لا نعيد OCR بلا سبب. إذا كانت الطبقة ناقصة أو فاسدة، ننتقل إلى raster + OCR متعدد المحركات.

### PDF صورة فقط / كتاب ممسوح

Render عالي الدقة → معالجة ScanTailor/OpenCV/unpaper حسب الحاجة → OCR متعدد المحركات → consensus → layout → إخراج مشتق.

### صور منفردة / TIFF

Normalize → preprocessing → OCR ensemble → img2pdf/OCRmyPDF عند الحاجة.

### DjVu

DjVuLibre للقراءة والتحويل، مع الاحتفاظ بالملف الأصلي وعدم استبداله.

## محركات مشروطة

Surya ممتاز للـOCR وتحليل التخطيط، لكنه لا يدخل قلب المجموعة المجانية غير المشروطة لأن ترخيص أوزانه النموذجية يختلف عن ترخيص الكود. لذلك يبقى **license-gated** ولا يُشغّل تلقائيًا إلا بعد التحقق من شروط الإصدار والاستخدام.

Real-ESRGAN كذلك يدخل في مسار الاستعادة الاختياري، مع فحص ترخيص الأوزان منفصلًا عن ترخيص الكود، ومع بوابة تمنع أي تحسين قد يخترع حرفًا أو يغير معلومة.

## التكلفة

المسار الأساسي مصمم ليكون **مجانيًا ولا يحتاج اشتراكًا مدفوعًا**. قد تحتاج بعض المحركات إلى مساحة تخزين وCPU/GPU محليين، وهذه موارد تشغيل وليست اشتراكًا في خدمة خارجية.

## الحوكمة

- الاكتشاف الآلي لا يعني التثبيت الآلي.
- الإصدار الجديد لا يُعتبر مجانيًا إلى الأبد لمجرد أن الإصدار السابق كان مجانيًا.
- كل ترقية تمر عبر فحص الترخيص والأمن.
- لا تعديل مباشر على `main`.
- أي تغيير يمر عبر PR محمي واختبارات.
- لا تُنشر نسخة مشتقة من كتاب محمي الحقوق قبل فحص حقوق إعادة التوزيع.
