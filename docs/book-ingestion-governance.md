# حوكمة إدخال الكتب

هذه الطبقة تربط مسار الكتب بنواة الحوكمة دون إدخال نصوص جديدة.

قبل السماح بعملية `ingest` أو `publish` أو `export` يجب أن يتوفر:

- `resourceId` وهوية المورد.
- `source` معروف.
- `provenance` يصف أصل المورد وإصداره.
- سجل حقوق بحالة تسمح بإعادة التوزيع.
- نتيجة `validation` مساوية لـ`passed`.

الحالات `unknown` و`rights-unclear` و`restricted` تُرفض تلقائيًا.

هذا العقد لا يقوم بعملية OCR ولا يكتب نص الكتاب ولا ينشئ محتوى علميًا؛ وظيفته حماية بوابة الإدخال والتصدير من تجاوز الحوكمة. لذلك يمكن ربطه لاحقًا بمخزن الكتب وOCR بعد إثبات سلامة تلك الطبقات.
