# جلب الكتب المحكوم

هذه الطبقة لا تنفذ HTTP fetching. إنها تخطط للجلب فقط بعد اجتياز موصل المصدر، وتتحقق مسبقًا من الرابط ونوع المحتوى وحجم المحتوى.

الحد الأقصى الحالي 25 MiB، والأنواع المسموح التخطيط لها PDF وPlain Text وEPUB. أي نقص أو مخالفة ينتج `blocked`.

الجلب الفعلي، التخزين، وفحص المحتوى سيبقى في طبقات منفصلة، ولن يُسمح له بتجاوز بوابات المصدر والحقوق وprovenance والتحقق.
