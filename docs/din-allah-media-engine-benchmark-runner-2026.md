# Din Allah Media Engine — Benchmark Runner 2026

This layer turns the clean Media Engine contract into an executable, reproducible benchmark interface.

## Design

The runner accepts a generated or lawfully cleared video supplied outside ordinary PR CI. It verifies decodability and basic media streams, then applies provenance and rights gates before any score fields may be populated.

VBench-2.0 is the primary external benchmark and VBench the secondary baseline. Their measurements are evaluation signals only; they are not religious rulings or scientific evidence. VBench-2.0 evaluates 18 fine-grained capability dimensions and supports customized-video evaluation. See the official benchmark documentation: https://github.com/Vchitect/VBench/tree/master/VBench-2.0

## GPU stage

Actual model generation is intentionally external to normal GitHub PR CI. A dedicated GPU runner can generate the fixed prompt suite for each candidate, retain the video outside Git, and pass only a compact JSON scorecard back to this repository.

Minimum recorded provenance:

- provider
- model/checkpoint
- exact model revision or commit
- generation timestamp
- hardware/runtime profile
- prompt ID and prompt text hash
- provider terms URL and usage status
- input/reference rights status
- content credentials/provenance metadata when available

## Fail-closed policy

Missing provenance, missing rights, unreadable video, or missing mandatory source metadata blocks publication. The runner never invents VBench scores. Quran Arabic text and Quran recitation remain separate verified assets and are never generated by the video model.
