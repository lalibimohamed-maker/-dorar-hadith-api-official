# الكشف التلقائي للغة الصوت — «يا بوابة العلم»

تعمل طبقة الصوت على اكتشاف لغة كلام المستخدم تلقائيًا ثم جعل لغة الرد متوافقة معها، مع عدم جعل الترجمة مصدرًا أصليًا.

## السلوك الافتراضي

- `auto_detect_language = true`.
- لغة الرد تتبع لغة المستخدم عند تجاوز عتبة الثقة.
- لغة الواجهة لا تتغير تلقائيًا بسبب الكلام ما لم يختر المستخدم ذلك.
- تثبيت لغة المحادثة متاح، والعودة إلى `Auto` متاحة.
- لا يحدث تبديل بسبب كلمة أجنبية مفردة أو اسم علم.

## المسار المحلي المفضل

`Wake Word → VAD → Language ID → STT → Confidence Fusion → Response → TTS`

المسار الأساسي لـLanguage ID هو `sherpa-onnx`، مع إمكان الاستفادة من Language Classifier في منظومة Silero، وبقاء نماذج Whisper متعددة اللغات مسارًا احتياطيًا. توثيق sherpa-onnx يذكر دعم Spoken Language Identification، إضافة إلى ASR وTTS وVAD وKeyword Spotting، وعلى iOS وAndroid وWebAssembly وغيرها. citeturn873441search4turn873441search8

## منع الالتباس

إذا كانت الثقة منخفضة:

1. لا نبدّل اللغة.
2. نحافظ على لغة المحادثة الحالية.
3. نعيد التقدير مع مقطع أطول.
4. نسأل سؤال توضيح قصيرًا فقط عند الضرورة.

في الكلام المختلط، تكون لغة الجواب هي اللغة الغالبة للمحادثة، مع إبقاء أسماء الأعلام والاقتباسات والنصوص الأصلية كما هي.

## العربية

تُعامل العربية وقراءة القرآن على أنها حالات خاصة من ناحية الدقة، لذلك يجب اختبار اللهجات والضوضاء والتشكيل وأسماء السور والقراء قبل تغيير النموذج الافتراضي.

Silero VAD موثق بأنه سريع وخفيف، وتذكر الوثائق أن منظومته تتضمن أيضًا Language Classifier، مع ترخيص MIT. citeturn873441search1

## الترجمة

الترجمة طبقة فهم/عرض فقط:

- النص العربي الأصلي يبقى محفوظًا.
- ترجمة الآية أو الحديث توسم بلغتها ومصدرها.
- لا يجوز استبدال المصدر الأصلي بترجمة صامتة.
- أي نتيجة علمية مترجمة تبقى مرتبطة بالمرجع الأصلي.

## الخصوصية

- المعالجة المحلية مفضلة.
- لا حفظ للصوت الخام افتراضيًا.
- أي تعرف خارجي على الكلام يحتاج موافقة صريحة.
- بيانات اللغة قابلة للحذف ضمن سجل الجلسة.

## القياس

قبل اعتماد أي لغة جديدة أو نموذج جديد، نقيس:

`Language-ID accuracy` + `false-switch rate` + `short-utterance accuracy` + `Arabic dialect robustness` + `mixed-language robustness` + `latency` + `privacy`.

الهدف ليس دعم أكبر عدد من اللغات اسميًا، بل تقديم أعلى جودة ممكنة لكل لغة مع الحفاظ على سلوك آمن وثابت.
