# GPU / VRAM Acceleration Fabric 2026

هذه الطبقة تجعل GPU مسرّعًا اختياريًا لا شرطًا لتشغيل موسوعة دين الله.

## المبدأ

- البرمجيات المفتوحة والمعايير المفتوحة أولًا.
- لا شراء GPU ولا خدمة Cloud GPU شرطًا لتشغيل الوظائف الأساسية.
- CPU fallback إلزامي.
- لا نملأ VRAM بالكامل؛ نحتفظ بهامش أمان للـbuffers وdecode/encode وworkspace.
- لا تعمل جميع نماذج الصورة/الفيديو معًا افتراضيًا.

## التجريد والتنفيذ

ONNX Runtime هو طبقة التنفيذ المتعددة العتاد. يمكن اختيار CUDA/TensorRT لـNVIDIA، MIGraphX لـAMD، OpenVINO لـIntel، DirectML/WinML على Windows، وWebGPU في المتصفح، مع CPU/XNNPACK fallback وفق الدعم الفعلي. راجع التوافق والترخيص لكل runtime والإصدار قبل التوزيع.

PyTorch يمكن استخدامه للنماذج البحثية التي تحتاجه، مع مراقبة allocated/reserved/free VRAM وإحصاءات الذاكرة.

## الفيديو والصور

FFmpeg هو مسار decode/encode. فوقه يمكن استخدام BasicVSR++ وRealBasicVSR وST-AVSR للمسار الزمني، وThera/EQSR/UltraSR للمقياس الاعتباطي، وReal-ESRGAN/SwinIR/HAT للترميم والجودة. يتم الاختيار بواسطة Orchestrator؛ تشغيل عدة محركات لا يحدث إلا عندما تكون أدوارها متكاملة ويثبت benchmark فائدتها.

## أهداف الدقة

8K، 12K، 16K، و24K أهداف إخراج ممكنة عندما يسمح المصدر والوقت والعتاد. 24K لا تعني native 24K detail. يجب حفظ دقة المصدر ومقاس الإخراج والمحركات والنماذج والإصدار والتمريرات والـhash/provenance.

## أجهزة مرجعية اختيارية

- فئة RTX 5090 32GB كمرجع عالي الأداء فقط.
- فئة 24GB GPU كمرجع عالي VRAM.
- بطاقات/معالجات مدمجة وأجهزة محمولة عند دعم runtime.
- CPU-only كمسار fallback إلزامي.

هذه أمثلة عتادية، وليست شرطًا ولا وعدًا بأنها مجانية. الموسوعة لا تعتمد على شراء عتاد بعينه.

## قواعد الحقوق والصدق

ترخيص البرنامج لا يساوي ترخيص checkpoint أو voice/model/data asset. يجب فحص كل model checkpoint والأصل المرئي/السمعي منفصلًا. التفاصيل التي يعيد AI بناءها يجب ألا تعرض على أنها تفاصيل أصلية للمصدر.
