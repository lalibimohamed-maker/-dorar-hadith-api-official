# طبقة التقنيات — Technology Layer 2026

هذه الطبقة تسجل التقنيات المفتوحة والمعايير العامة التي تعتمد عليها موسوعة دين الله، مع إبقاء الاختيار قابلاً للقياس والترقية.

## مبدأ التكلفة

- تُفضّل المعايير المفتوحة والبرمجيات الحرة/مفتوحة المصدر والاستضافة الذاتية.
- «مجاني» هنا يعني أن البرنامج/المعيار متاح دون رسوم ترخيص وفق شروطه؛ ولا يعني أن الخوادم أو التخزين أو GPU مجانية إلى الأبد.
- لا يُعتمد على خدمة مدفوعة أو مغلقة عندما يوجد بديل مفتوح مناسب دون توثيق سبب الاستثناء.

## Web Platform

- PWA / Service Workers / Cache APIs: للتثبيت والعمل دون اتصال والتخزين المؤقت.
- IndexedDB: تخزين محلي منظم.
- Web Workers / Shared Workers: نقل المعالجة الثقيلة خارج واجهة المستخدم.
- WebRTC: الاتصال اللحظي ومشاركة الوسائط عند الحاجة.
- Web Share: مشاركة المحتوى عبر أهداف الجهاز المتاحة.
- Web Crypto / CSP / SRI: طبقات أمن المتصفح.
- Web Components: مكونات قابلة لإعادة الاستخدام عند الحاجة.

## الأداء والحوسبة

- WebAssembly (Wasm): تشغيل الخوارزميات الثقيلة محليًا ضمن بيئة sandbox.
- SIMD/threads عند دعم المتصفح والعتاد وبعد قياس الفائدة.
- WebGPU: GPU للرسوميات والحوسبة والمهام المناسبة، مع fallback آمن عند عدم الدعم.
- WebCodecs: معالجة الوسائط عندما يكون دعم المتصفح مناسبًا.
- Web Audio API: المعالجة الصوتية داخل المتصفح عند الحاجة.

WebAssembly وWebGPU معياران مفتوحان في منظومة W3C، ولذلك يُسجلان كتقنيات platform لا كخدمات تجارية.

## الواجهة والوصول

- HTML/CSS/TypeScript.
- RTL وUnicode-first للعربية.
- WCAG وARIA وإتاحة لوحة المفاتيح وقارئات الشاشة.
- Responsive design وprogressive enhancement.

## البناء والتطبيق

- Vite/Rolldown لمسار البناء.
- TypeScript للتحقق الساكن.
- Lockfiles وreproducible builds حيثما أمكن.
- Web Workers/Wasm لتقليل ضغط main thread.

## البيانات والتكامل

- JSON/JSONL للبيانات القابلة للتبادل.
- JSON-LD/Schema.org للبيانات الدلالية العامة.
- OpenAPI لتوثيق واجهات HTTP عند الحاجة.
- HTTP caching وETag وcontent hashes للتحقق وإعادة الاستخدام.

## البحث والذكاء الدلالي

- Meilisearch للبحث النصي الفوري.
- Qdrant للبحث الدلالي والهجين.
- Reranking/embeddings تُعامل كطبقة استرجاع، ولا تُعتبر مصدرًا علميًا.
- المصدر الأصلي وprovenance يظلان المرجع النهائي.

## الوسائط

- AVIF/WebP مع fallback مناسب.
- Sharp لمعالجة الصور.
- Real-ESRGAN وSwinIR للترميم/رفع الدقة بعد اختبار الجودة.
- FFmpeg للصوت والفيديو.
- DeepFilterNet وRNNoise لتنقية الصوت ضمن التراخيص المسموحة.

## التنزيل والتخزين

- aria2 / Wget2 / curl للتنزيلات العامة المصرح بها.
- rclone لمسارات التخزين المتعددة.
- yt-dlp للوسائط المسموح بتنزيلها فقط.
- qBittorrent للتوزيع P2P للمحتوى المصرح به فقط.

## المراقبة والاعتمادية

- OpenTelemetry للـtraces/metrics/logs.
- Grafana OSS للتصور والتنبيه.
- Kopia وRestic للنسخ الاحتياطي والاستعادة.

## الأمن وسلسلة التوريد

- CodeQL للتحليل الساكن.
- Trivy / Grype / OSV-Scanner لفحص الثغرات.
- Syft للـSBOM.
- Gitleaks للأسرار.
- Zizmor لتدقيق GitHub Actions.
- Scorecard لتقييم ممارسات سلسلة التوريد.
- تثبيت Actions على commit SHA حيث تسمح البنية.

## قواعد الاختيار

كل تقنية تُقيّم على:

1. الأمن.
2. الترخيص.
3. الكلفة التشغيلية.
4. الأداء.
5. دعم العربية وRTL عند الصلة.
6. النضج والتوافق.
7. نشاط الصيانة.
8. قابلية الاستضافة الذاتية.
9. قابلية إعادة الإنتاج.
10. الإسناد والحقوق.

التصنيف: `Adopt` / `Trial` / `Assess` / `Hold` / `Deprecated`.

لا تتم ترقية تقنية تلقائيًا لمجرد صدور إصدار أحدث؛ الترقية الكبيرة تحتاج benchmark ومراجعة وتحققًا من الأمن والتوافق وعدم فقدان provenance.

## سياسة «مجاني»

لا نعد المستخدم بأن أي خدمة استضافة أو بنية تحتية ستبقى مجانية مدى الحياة. نثبت فقط البرمجيات والمعايير التي تسمح تراخيصها بالاستخدام المطلوب، ونفضّل self-hosting لتقليل الاعتماد على الخدمات المدفوعة.
