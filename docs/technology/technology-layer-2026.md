# طبقة التقنيات — Technology Layer 2026

هذه الطبقة تسجل التقنيات المفتوحة والمعايير العامة التي تعتمد عليها موسوعة دين الله، مع إبقاء الاختيار قابلاً للقياس والترقية.

## مبدأ التكلفة

- تُفضّل المعايير المفتوحة والبرمجيات الحرة/مفتوحة المصدر والاستضافة الذاتية.
- «مجاني» يعني أن البرنامج/المعيار متاح دون رسوم ترخيص وفق شروطه؛ ولا يعني أن الخوادم أو التخزين أو GPU مجانية إلى الأبد.
- لا يُعتمد على خدمة مدفوعة أو مغلقة عندما يوجد بديل مفتوح مناسب دون توثيق سبب الاستثناء.

## لوحة المفاتيح والإدخال

- **Keyman**: المسار الرئيسي متعدد المنصات؛ يدعم العربية وتخطيطات متعددة، ويُقيّم بحسب الجهاز والإصدار.
- **OpenBoard**: مسار Android/FOSS.
- **AnySoftKeyboard**: مسار Android للاقتراح والتصحيح، مع حزمة عربية عند توفرها.
- **ArabicIME**: مسار تجريبي لإدخال العربية على سطح المكتب.
- **Arabic Intelligent Input Layer**: طبقة موسوعة دين الله للتطبيع والبحث العربي، مع إبقاء النص الأصلي بلا تعديل.
- تطبيع Unicode والتشكيل والرموز القرآنية يتم في الإدخال/البحث فقط، ولا يغير Corpus أو النصوص الأصلية.

### «يا بوابة العلم» — Voice Layer

الهدف: تجربة صوتية عربية هادئة ودقيقة تشبه المساعدات الصوتية، مع معالجة محلية أولًا حيثما أمكن.

- **Wake word:** `openWakeWord` كإطار مفتوح، مع نموذج عربي مخصص مقترح باسم `ya_bawabat_al_ilm`. النماذج الجاهزة الحالية في openWakeWord تركز على الإنجليزية؛ لذلك لا يُعلن دعم العربية الجاهز قبل تدريب النموذج واختباره. `micro-wake-word` مسار بديل للأجهزة المحدودة.
- **VAD:** `Silero VAD` لعزل الكلام وتقليل التفعيلات الكاذبة.
- **STT الرئيسي:** `whisper.cpp` للتعرف المحلي متعدد اللغات، مع `faster-whisper` كبديل عالي الأداء.
- **تحسين الصوت:** `DeepFilterNet` أو `RNNoise` بحسب latency/quality؛ لا نطبقهما معًا افتراضيًا إلا بعد benchmark.
- **TTS الرئيسي:** `Piper1-GPL` محليًا، مع صوت عربي `ar_JO` متاح، والتحقق من ترخيص كل نموذج صوت قبل توزيعه.
- **Web fallback:** Web Speech API عند ملاءمة المتصفح، مع تفضيل on-device recognition عندما تكون متاحة؛ ليست backend موثوقة وحيدة لأن بعض المتصفحات قد تستخدم خدمة خادمية.

### جودة «يا بوابة العلم»

- فصل الكلام عن الصمت والضجيج والموسيقى قدر الإمكان.
- نبرة افتراضية هادئة وواضحة، مع التحكم في السرعة والارتفاع والوقفات ومستوى الصوت.
- دعم تعدد الأصوات واللغات مع ملف صوت مستقل لكل لغة.
- لا إرسال للصوت إلى خادم دون إذن صريح.
- حذف التسجيل الخام بعد المعالجة ما لم يطلب المستخدم الحفظ.
- مؤشر واضح عند استخدام الميكروفون وزر إيقاف فوري.
- Wake-word verification + VAD + confidence threshold + cooldown لمنع التفعيل المتكرر.
- لا اعتماد إنتاجي نهائي لـ«يا بوابة العلم» قبل قياس false-accept / false-reject في ضوضاء ولهجات عربية متعددة.

## إعدادات الهاتف والويب

- الميكروفون: تشغيل/إيقاف.
- wake word: تشغيل/إيقاف.
- حساسية «يا بوابة العلم» قابلة للضبط.
- مصدر الإدخال: ميكروفون الجهاز أو سماعة/بلوتوث عندما يسمح النظام.
- اللغة واللهجة والـlocale.
- سرعة الكلام وpitch والوقفات ومستوى الصوت.
- اختيار الصوت لكل لغة.
- وضع الخصوصية: محلي فقط / خدمة ويب عند السماح الصريح.
- حفظ التسجيلات: متوقف افتراضيًا.
- مؤشر الاستماع وإيقاف فوري.
- اختصار زر/لوحة مفاتيح عند عدم دعم wake word.

## الصوت والخصوصية والأمان

- موافقة صريحة على الميكروفون.
- لا تسجيل في الخلفية افتراضيًا.
- معالجة محلية أولًا.
- لا استخدام لخدمة Web Speech الخارجية إلا مع كشف المسار وموافقة صريحة عندما تكون المعالجة خادمية.
- `getUserMedia()` يتطلب secure context، والوصول إلى الميكروفون يخضع لأذونات المتصفح وPermissions Policy.
- `Permissions-Policy: microphone=(self)` كقاعدة افتراضية للموسوعة.
- الصوت الخام لا يدخل الـCorpus ولا يصبح مصدرًا علميًا.

التصنيف: `Adopt` / `Trial` / `Assess` / `Hold` / `Deprecated`.

لا تتم ترقية تقنية تلقائيًا لمجرد صدور إصدار أحدث؛ الترقية الكبيرة تحتاج benchmark ومراجعة وتحققًا من الأمن والتوافق وعدم فقدان provenance.

## سياسة «مجاني»

لا نعد المستخدم بأن أي خدمة استضافة أو بنية تحتية ستبقى مجانية مدى الحياة. نثبت فقط البرمجيات والمعايير التي تسمح تراخيصها بالاستخدام المطلوب، ونفضّل self-hosting لتقليل الاعتماد على الخدمات المدفوعة.
