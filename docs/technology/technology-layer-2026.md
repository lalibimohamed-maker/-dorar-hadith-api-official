# طبقة التقنيات — Technology Layer 2026

هذه الطبقة تسجل التقنيات المفتوحة والمعايير العامة التي تعتمد عليها موسوعة دين الله، مع إبقاء الاختيار قابلاً للقياس والترقية.

## مبدأ التكلفة

- تُفضّل المعايير المفتوحة والبرمجيات الحرة/مفتوحة المصدر والاستضافة الذاتية.
- «مجاني» يعني أن البرنامج/المعيار متاح دون رسوم ترخيص وفق شروطه؛ ولا يعني أن الخوادم أو التخزين أو GPU مجانية إلى الأبد.
- لا يُعتمد على خدمة مدفوعة أو مغلقة عندما يوجد بديل مفتوح مناسب دون توثيق سبب الاستثناء.

### «يا بوابة العلم» — Voice Layer

الهدف: تجربة صوتية عربية هادئة ودقيقة تشبه نموذج المساعدات الصوتية، مع معالجة محلية أولًا حيثما أمكن.

- **Wake word:** `openWakeWord` كإطار تدريب/تشغيل مفتوح، مع التنبيه إلى أن النماذج الجاهزة المدرجة حاليًا تركز على الإنجليزية؛ لذلك لا يُعلن دعم «يا بوابة العلم» قبل تدريب واختبار نموذج عربي مستقل. البديل القابل للتوسع: `micro-wake-word` عندما يكون الجهاز محدود الموارد.
- **VAD:** `Silero VAD` لعزل الكلام عن الصمت والضجيج وتقليل التفعيلات الكاذبة.
- **STT الرئيسي:** `whisper.cpp` للتعرف المحلي متعدد اللغات، مع `faster-whisper` كمسار بديل عالي الأداء.
- **تحسين الصوت:** `DeepFilterNet` ثم `RNNoise` كمسارين حسب latency/quality، دون تطبيق السلسلتين معًا إلا بعد benchmark حتى لا نضيف تشويهًا.
- **TTS الرئيسي:** `Piper (OHF-Voice/piper1-gpl)` محليًا، مع أصوات عربية متاحة، والتحقق من ترخيص كل نموذج صوت قبل التوزيع.
- **Web fallback:** Web Speech API عند ملاءمة المتصفح، مع تفضيل on-device recognition عندما تكون متاحة، لأن بعض المتصفحات قد ترسل الصوت إلى خدمة خارجية. لا يُستخدم كمسار موثوق وحيد.

### جودة «يا بوابة العلم»

- لا خلط بين الصوت والكلام والموسيقى قدر الإمكان عبر VAD + denoising + segmentation.
- نبرة افتراضية هادئة وجوهرية، مع التحكم في السرعة والارتفاع والوقفات ومستوى الصوت.
- دعم تعدد الأصوات واللغات، مع voice profile مستقل لكل لغة.
- عدم إرسال الصوت إلى خادم دون إذن صريح.
- حذف التسجيل الخام بعد انتهاء المعالجة ما لم يطلب المستخدم الحفظ.
- إشارة واضحة عند استخدام الميكروفون.
- زر إيقاف فوري.
- عدم تشغيل الميكروفون تلقائيًا من iframe غير موثوق.
- `Permissions-Policy: microphone=(self)` كقاعدة افتراضية، وتضييقها عند الحاجة.
- HTTPS/secure context فقط لـ`getUserMedia()`.
- Wake-word verification + VAD + confidence threshold + cooldown لمنع التفعيل المتكرر.
- لا تصبح عبارة «يا بوابة العلم» متاحة كـwake word رسمي إلا بعد قياس false accept / false reject في لهجات عربية متنوعة.

## إعدادات الهاتف والويب

يجب أن تكون إعدادات الصوت متاحة عبر صفحة إعدادات الموسوعة، مع احترام إعدادات نظام التشغيل:

- الميكروفون: تشغيل/إيقاف.
- wake word: تشغيل/إيقاف.
- «يا بوابة العلم»: اختيار/تعطيل، مع إمكانية تغيير حساسية التفعيل.
- مصدر الإدخال: ميكروفون الجهاز أو سماعة/بلوتوث عندما يسمح النظام.
- اللغة واللهجة.
- سرعة الكلام وpitch والوقفات.
- اختيار الصوت.
- وضع الخصوصية: محلي فقط / مسار ويب عند السماح.
- حفظ التسجيلات: افتراضيًا متوقف.
- عرض مؤشر الاستماع.
- سماح تلقائي محدود: ممنوع افتراضيًا.
- اختصار لوحة المفاتيح/زر الشاشة لبدء الاستماع عند عدم دعم wake word.

## سياسات واجهة الصوت والخصوصية

- موافقة صريحة على الميكروفون.
- لا تسجيل في الخلفية دون حالة واضحة ومسموح بها.
- معالجة محلية أولًا.
- عند استخدام Web Speech، فحص ما إذا كان التنفيذ محليًا أم خادميًا قبل إرسال الصوت، لأن Web Speech API قد تستخدم خدمة خادمية في بعض المتصفحات.
- الصوت الخام لا يدخل الـCorpus.
- الصوت لا يتحول إلى «معلومة موثوقة»؛ النتيجة النصية تحتاج نفس provenance والحقوق إذا أريد حفظها كمادة.

## سياسة «مجاني»

لا نعد المستخدم بأن أي خدمة استضافة أو بنية تحتية ستبقى مجانية مدى الحياة. نثبت فقط البرمجيات والمعايير التي تسمح تراخيصها بالاستخدام المطلوب، ونفضّل self-hosting لتقليل الاعتماد على الخدمات المدفوعة.
