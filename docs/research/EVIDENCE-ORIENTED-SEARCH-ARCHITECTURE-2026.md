# Evidence-Oriented Research Search Architecture — 2026

## الفكرة

المطلوب ليس جمع أكبر عدد من محركات البحث، بل توجيه **كل سؤال إلى الاختصاص الذي يستطيع تحصيل أفضل أدلة له**، ثم جمع الأدلة المستقلة في طبقة تحكم واحدة.

## طبقات الجيش

1. **الاكتشاف العام**: SearXNG + Common Crawl لاكتشاف المسارات والصفحات والفهارس، مع اعتبار النتائج الأولية اكتشافًا لا إثباتًا.
2. **المصادر الأولية والرسمية**: المواقع الرسمية، المكتبات الوطنية، الأرشيفات والمؤسسات، مع أولوية المصدر الأصلي المباشر.
3. **العلم والأبحاث**: OpenAlex وCrossref وSemantic Scholar وarXiv وEurope PMC وZenodo وUnpaywall؛ البحث هنا لإحضار الدراسات، بيانات الاستشهاد، النسخ المفتوحة ومواقع النصوص المتاحة.
4. **الكتب والمكتبات**: Open Library وInternet Archive وLibrary of Congress ومؤشرات المكتبة الداخلية.
5. **الصورة والوثيقة**: IIIF وWikimedia/Openverse وطبقة معالجة الكتب المحلية، مع OCR متعدد المحركات.
6. **الصوت والمرئي**: أرشيفات المؤسسات وInternet Archive وOpenverse، وواجهات المنصات مثل YouTube فقط ضمن حدود الحصة والشروط؛ لا تعتبر المنصة نفسها مصدرًا للحقيقة.
7. **التحليل الداخلي**: Apache Tika + الفهرس المحلي + البحث الدلالي للCorpus.

## القيادة والتنسيق

القيادة ليست «محرك إجابة» واحدًا فقط. هي سلسلة:

`Query Decomposer → Specialist Dispatcher → Collectors → Normalizer → Deduplicator → Provenance Tracker → Source Quality Ranker → Independence Clusterer → Claim/Evidence Linker → Contradiction Detector → Sufficiency Gate → Citation Builder → Answer Synthesizer → Review/Uncertainty Gate`

يمكن تشغيل أكثر من جامع بالتوازي. المحرك الجامع لا يرفع ثقة الادعاء لمجرد كثرة النسخ: عشر صفحات تنقل عن المصدر نفسه = مصدر واحد من ناحية الاستقلال.

## قاعدة اليقين

لا نستخدم عبارة «علم يقين» لمجرد اتفاق محركات البحث. القوة العلمية للنتيجة تُبنى من:

- أصالة المصدر ومباشرته.
- استقلال المصادر عن بعضها.
- سلامة الوثيقة والنسخة المستخدمة.
- قوة الإسناد/الاستشهاد.
- حداثة المعلومة عندما تكون الحداثة ذات صلة.
- اتفاق أدلة مستقلة.
- إبقاء التعارض ظاهرًا بدل حسمه خفيًا.

وعند عدم كفاية الأدلة يكون الناتج **غير كافٍ** أو **متعارض** بدل اختراع جواب.

## مبدأ موسوعة دين الله

هذه الطبقة لا تكتب فوق Corpus ولا تحول نتيجة بحث إلى مادة علمية موثقة تلقائيًا. الاكتشاف يظل اكتشافًا حتى يمر عبر حدود المصدر والحقوق والتحقق والإثبات.

## الأدوات التي ينبغي أن تبقى خارج القلب المجاني غير المشروط

أي API أو نموذج له رسوم، أو شروط استخدام تفرض اعتمادًا تجاريًا، أو أوزان ترخيصها أكثر تقييدًا من الكود، يبقى `license-gated` أو `quota-gated` ولا يصبح تلقائيًا جزءًا من القلب.

## مصادر مرجعية للبنية

SearXNG هو metasearch قابل للاستضافة الذاتية ويجمع محركات متعددة، ويدعم فئات للويب والصور والفيديو والأخبار والعلوم والملفات. OpenSearch يوفر بحثًا نصيًا، هجينًا، وإعادة ترتيب وRAG. Crossref يوفر REST API عامًا دون تسجيل. Europe PMC يوفر REST API للمنشورات والنصوص الكاملة المفتوحة. Library of Congress يوفر API عامًا للكتب والصور والفيديو والصوت وOCR. Open Library يدعم البحث في الكتب وداخل الكتب مع حدود استخدام واضحة. Common Crawl يوفر فهارس وأرشيفًا عامًا مجانيًا للبيانات. Openverse يبحث في وسائط ذات تراخيص مفتوحة لكنه ينبه إلى ضرورة التحقق من ترخيص كل عمل. YouTube Data API مجاني ضمن حصة، لكنه مقيد بحصة وشروط المنصة.
