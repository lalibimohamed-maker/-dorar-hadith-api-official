# سجل الحقوق

سجل الحقوق طبقة تنفيذية بين اكتشاف المصدر وبين السماح بإعادة التوزيع. وجود المورد على الويب، أو إمكان قراءته، أو ظهوره في نتائج البحث لا يثبت حق إعادة نشره.

كل مورد يمر إلى `publish` أو `export` يحتاج سجلًا مكتملًا يتضمن:

- `resourceId`
- `status`
- `basis`
- `source`
- `verifiedAt`
- `verifier`

ولا يكفي وجود `status` وحده. أي سجل ناقص أو غير صالح يفشل مغلقًا.

الحالات الوحيدة المسموح بها لإعادة التوزيع هي `redistributable` و`licensed` و`public-domain`.

أما `rights-unclear` و`restricted` و`unknown` فتبقى محجوبة.

## نواة الحوكمة

`orchestration-kernel` و`algorithmic-governance-mesh` يتحققان من سجل الحقوق قبل مسار النشر/التصدير. سجل الحقوق يقدم الدليل ولا يمنح الصلاحية بذاته؛ قرار التنفيذ يبقى لنواة الحوكمة.

## عدم التأثير على الـCorpus

إنشاء سجل الحقوق أو تحديثه لا يغير النص الديني أو Corpus أو الببليوغرافيا العلمية. السجل يصف حالة المورد وحقوق استخدامه فقط.

## Fail-closed

النقص، الغموض، التعارض، أو عدم تحقق الحقوق يؤدي إلى المنع بدل التخمين أو الترقية الضمنية.
