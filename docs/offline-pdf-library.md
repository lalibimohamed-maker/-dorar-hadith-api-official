# قراءة PDF دون اتصال

وضعت موسوعة دينُ الله طبقة Offline للكتب التي اجتازت حوكمة المصدر والحقوق والتحقق من سلامة الملف.

## دورة الكتاب

1. الكتاب يمر أولًا من سياسة `src/book-cache-policy.js`؛ لا يُسمح بالتخزين المحلي لكتاب بلا مصدر ورابط، provenance موثّق، حالة حقوق مسموحة، والتحقق من الملف.
2. المتصفح ينزّل الـPDF كاملًا عند اختيار **إتاحة الكتاب دون اتصال**.
3. يتم فحص عدد البايتات ثم SHA-256 قبل الحفظ المحلي. الملف الذي يفشل الفحص لا يدخل المكتبة Offline.
4. النسخة المؤكدة تُحفظ في Cache Storage، بينما تُحفظ بيانات الفهرسة والحالة في IndexedDB.
5. يمكن للواجهة عرض المكتبة، فتح كتاب محفوظ، أو حذفه من الجهاز.
6. يطلب التطبيق `navigator.storage.persist()` عندما يكون مدعومًا حتى تكون البيانات أكثر مقاومة للإخلاء تحت ضغط التخزين؛ لا يوجد ضمان مطلق ضد حذف بيانات الموقع من إعدادات المتصفح أو النظام.

## تشغيل التطبيق دون إنترنت

`public/sw.js` يتولى اعتراض طلبات PDF: إذا كانت النسخة موجودة محليًا يعيدها مباشرة دون شبكة. إذا لم توجد، لا يدّعي التطبيق أنها متاحة Offline، ويعيد حالة 504 بدل عرض ملف ناقص أو قديم.

`public/manifest.webmanifest` يعرّف التطبيق كتطبيق ويب RTL ويمكن ربطه لاحقًا بواجهة الموسوعة الحالية.

## مهم للواجهة النهائية

هذا المستودع حاليًا يحتوي طبقة API ومكوّنات المحتوى أكثر من كونه تطبيق متصفح كاملًا. لذلك هذه PR تثبت البنية البرمجية والقواعد المطلوبة للـOffline، ولا تدّعي أن كل صفحات الواجهة الحالية أصبحت PWA تلقائيًا. عند ربط واجهة الموسوعة، يجب استدعاء `registerOfflineServiceWorker()` مرة واحدة، ثم استخدام `downloadPdfForOffline()` لزر التنزيل، و`openOfflinePdf()` لفتح النسخة المحلية.

## الكتب الكبيرة

التخزين المحلي يعتمد على حصة المتصفح؛ لذلك لا ينبغي تنزيل آلاف الكتب تلقائيًا. النموذج المعتمد هو تنزيل الكتاب أو حزمة كتب يختارها المستخدم، مع إظهار الحجم، المساحة المتاحة، نسبة التقدم، وحالة التحقق.
