# First Evidence-Driven Scientific-Religious Video Prototype

## Subject
Ant communication and the Quranic witness in Surah An-Naml 27:18.

## Scientific framing
The prototype does not claim that ants speak like humans. It uses the narrower sourced claim that ants communicate through multiple mechanisms, including chemical, tactile and vibrational signalling. The 2021 Scientific Reports study reports context-dependent stridulatory signalling in ants; the 2017 Animal Behaviour review surveys acoustic communication in ant societies.

## Quranic layer
The prototype contains Surah An-Naml 27:18 as the Quranic witness. The Arabic source layer is kept verbatim. Translation is a separate asset and is not substituted for the Arabic source.

## Why an animatic first
The first run must prove that the encyclopedia can deterministically transform an evidence manifest into a real media artifact without downloading or embedding uncleared third-party footage or an unlicensed recitation. The prototype therefore uses an original vector animatic and renders a real MP4 in CI.

## Production handoff
The same manifest can later accept rights-cleared scientific footage or original generated scenes, a rights-cleared recitation, word-level alignment, multilingual meanings, color-purity processing and the 48K-class mastering pipeline already registered in Engine Evolution.
