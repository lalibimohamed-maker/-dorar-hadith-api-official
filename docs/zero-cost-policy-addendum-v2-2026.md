# Zero-Cost-First Addendum

The project is designed so that lack of money or a payment card is never a prerequisite for accessing the core encyclopedia.

- Core reading is free.
- Core search is free.
- Approved downloads are free when redistribution rights permit.
- Web/PWA access does not require an app-store developer membership.
- Supported localized presentations are free to access.
- No single paid provider is required for core operation.
- No paid API key is required for core reading/search.
- Open-source, self-hostable and free-tier components are preferred.
- When a free quota is exhausted, the system degrades to cached/local/offline/queued paths instead of silently generating a bill.
- Paid infrastructure may exist only as an optional accelerator, mirror, or community-provided store channel.

The project does not promise that a third-party service will remain free forever or provide unlimited bandwidth/storage. It promises that such a service is not a mandatory financial dependency for core access.

Free access, open-source software, public-domain content, and permission to redistribute a third-party asset remain distinct rights states. Every external book, image, audio recording, video, translation, font and dataset must pass the rights gate before bundling or re-hosting.
