# Rechercher — Global multilingual revision v2

This layer inventories multilingual Islamic discovery sources and records complete documented API surfaces when verified. It does not infer undocumented endpoints and it never grants acquisition or redistribution rights.

## Native APIs
- Quranpedia: REST API plus official versioned dumps and changes/delta synchronization.
- IslamHouse: multilingual API family for books, articles, fatwas, audio, video, Quran and attachments.
- QuranEnc: Quran translation/tafsir API surface.
- HadeethEnc: languages → categories → paginated hadith records → individual hadith, with full multilingual discovery.

## Discovery-only sources
Additional multilingual sites are catalogued as web-discovery until an official, documented API is verified.

## Acquisition boundary
Discovery metadata is independent from Corpus and from the existing real-PDF acquisition engine. Rights verification remains a separate gate.
