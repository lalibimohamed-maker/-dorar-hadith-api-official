# @Rechercher — Learning Intelligence V4 Expansion 2026

V4 is an executable learning and research layer. It is not an authority layer and it is separate from acquisition/preservation.

## Required capabilities

- Knowledge-gap diagnosis.
- Prerequisite + similarity learning paths.
- Blocked-learning recovery.
- Explainable personalized recommendations.
- Four graph layers: Source Graph, Domain Ontology, Learning Resource Graph, Learner State Graph.
- Evidence/provenance trails.
- Contradiction-aware research.
- Confidence calibration.
- Teach-back and teacher/scholar review.
- Socratic guidance.
- Research apprenticeship.
- Cognitive-load controls.
- Transfer Laboratory.
- Continuous ablation/evaluation.
- Privacy-preserving learner model.
- Offline-first learning resilience.
- Translation Alignment Memory.
- Cross-language Terminology Map.
- Accessibility-adaptive presentation.

## Non-bypassable safety contract

Learning Intelligence must never control or disable PDF acquisition, bypass rights/provenance gates, mutate retained original PDFs, mutate canonical Quran Arabic, erase madhhab or scholarly differences, or make AI output authoritative without human review.

Unknown/restricted rights remain non-publishable. Source identity, immutable source hash, locator and rights state remain part of evidence trails. Disagreement and uncertainty remain explicit.

## Separation

Acquisition → Validation → Preservation → Knowledge → Evidence → Learning → Research → Human Review → Publication.

V4 consumes validated source/evidence state and does not rewrite authoritative source artifacts.

## Verification rule

A capability is complete only when executable code and deterministic tests cover its core behavior and safety contract. Documentation alone is not implementation.
