# شبكة محركات البحث الداخلية

محرك موسوعة دين الله واجهة بحث واحدة للمستخدم، ويمكنه خلفيًا تشغيل عدة مزودي بحث مستقلين بالتوازي. أسماء المزودين في الكود محايدة؛ لا نفترض توفر Google أو Bing أو Yandex أو أي خدمة بعينها دون API/ترخيص/شروط استخدام مناسبة.

## المبدأ

المستخدم يرى محركًا واحدًا. الشبكة الداخلية تجمع النتائج من مزودين متعددين، ثم تزيل التكرار وتُرجع النتائج بسرعة حتى لا يحجب مزود بطيء الإجابة.

## الحوكمة

نتيجة مزود خارجي هي **اكتشاف** وليست مصدرًا معتمدًا. لا تُدخل إلى Corpus ولا تتحول إلى Digital Master ولا تُستخدم لإعادة التوزيع إلا بعد Provenance + Rights + Validation.

## السرعة

- تنفيذ متوازٍ.
- حد أقصى لعدد المزودين.
- مهلة قصيرة لكل مزود.
- قبول النتائج الناجحة حتى عند فشل مزود آخر.
- قابلية إضافة cache/ranking لاحقًا.

## مزودو البحث

يمكن ربط Google/Bing/Yandex وغيرهم فقط عبر واجهاتهم الرسمية أو طرق يجيزها ترخيصهم وشروطهم. لا يوجد scraping خفي أو تجاوز للقيود.
