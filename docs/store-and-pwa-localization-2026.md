# Store, Web/PWA, and Localization Strategy

## Web/PWA is the universal baseline

The encyclopedia's canonical access path is a standards-based web application/PWA. Store publication is an additional distribution channel, not a prerequisite for accessing the service.

## Localization

The application detects a browser/OS locale but always permits an explicit language override. Detection selects the presentation locale; it never changes canonical scholarly text.

Phase-1 priority locales:

1. Arabic (`ar`)
2. English (`en`)
3. Chinese (`zh`)
4. Spanish (`es`)
5. Russian (`ru`)

Additional locales are registry entries rather than separate content silos.

## Store metadata

Store descriptions, screenshots and metadata should be localized independently from the canonical scholarly content. A translated store listing does not constitute a scholarly translation.

## Android

F-Droid is a possible free/open-source distribution path, subject to its inclusion policy and build requirements. Direct APK/repository distribution can be considered where legally and technically appropriate.

## Apple

The free Apple developer account permits development/testing capabilities, but App Store distribution requires Apple Developer Program membership. Accordingly, App Store distribution remains optional while web/PWA remains available.
