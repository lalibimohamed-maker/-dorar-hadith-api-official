# Zero-Cost-First Addendum

Core access to the Din Allah Encyclopedia is designed to remain free for users. The architecture must not require a paid provider, paid API key, or app-store membership for core web/PWA access.

This is a zero-cost-first architecture, not a claim that every third-party service is unlimited or free forever. Published quotas and terms are respected; when a free provider reaches a limit, the system falls back to local/offline/cached/queued or independent permitted paths rather than silently creating a paid bill.

Core scholarly reading and search are free. Approved downloads are free when redistribution rights permit. External content is never rehosted merely because it is publicly viewable.

Phase-one localization priority is Arabic, English, Chinese, Spanish, and Russian. Locale detection selects presentation language, while canonical scholarly text and evidence status remain separate from machine translation.

Web/PWA is the baseline distribution path. Official app stores are secondary channels because store distribution can require developer membership fees. F-Droid is an additional Android FLOSS route subject to its review and inclusion requirements.

Internet Archive is treated as a separate external preservation/distribution target, not as a native extension of the GitHub account. Any integration must use separately managed credentials, least privilege, provenance metadata, rights gates, checksums, and protected review.
