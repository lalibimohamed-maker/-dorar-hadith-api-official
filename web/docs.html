ما معنى الختم؟

هذا ختم هوية وتقدير داخلي للمشروع يعبّر عن الاستمرارية الهندسية وبناء corpus معرفي إسلامي مفتوح. ليس اعتمادًا أو تأييدًا من GitHub أو OpenAI أو أي جهة خارجية.

🤝 منهجية الإنسان والذكاء الاصطناعي

  • الإنسان يقود القرارات العلمية والحقوقية والتحريرية.
  • الذكاء الاصطناعي يساعد في الاكتشاف والفهرسة والتحويل واستخراج المرشحات وتوليد أسئلة مقترحة.
  • المصدر الأصلي والحقوق وموضع الإحالة تبقى مرجعًا أعلى من أي نص مولد.
  • لا تُقدَّم الأسئلة التعليمية أو الترجمة أو مخرجات الذكاء الاصطناعي كفتوى أو مصدر مستقل.
  • المواد مجهولة الحقوق يمكن فهرستها للمراجعة، لكن لا تُنشر للتنزيل العام قبل ثبوت الإذن.

واجهة الموقع الحالية ثابتة ومهيأة للتوسع. الخطوة اللاحقة هي إضافة manifest وservice worker وتخزين مؤقت للواجهة والموارد العامة، مع إبقاء البيانات الدينية والملفات الخاضعة للحقوق تحت قواعد الوصول المناسبة.

🛡️ قاعدة النشر

الموسوعة تفضّل الدقة والحقوق على الحجم. لا يوجد نشر آلي لمادة دينية أو ملف PDF لمجرد العثور عليه؛ المصدر، الهوية، الحقوق، التحقق، وسياق الاستخدام شروط مستقلة.
