# تطبيق موسوعة دينُ اللّه — Mobile

هذا المجلد يجهّز نفس واجهة الموسوعة للعمل كتطبيق أصلي عبر Capacitor على iOS وAndroid، مع بقاء PWA ونسخة الويب من نفس المصدر.

## المبدأ

**وقف لله — مجاني مدى الحياة.** لا توجد اشتراكات أو سعر تنزيل للتطبيق نفسه. أي `Donate` ستبقى منفصلة ومخفية عن المستخدمين إلى أن تُعرف تكلفة البنية والمنصات الفعلية ويُقرر إدراجها.

## Offline-first

التطبيق ليس مجرد WebView يعتمد على الإنترنت:

- ملفات الواجهة ومواد التعلم التي تم تنزيلها تُخزّن محليًا.
- البحث في المحتوى المحلي يمكن أن يعمل دون اتصال.
- البحث العالمي في المصادر الحية يحتاج اتصالًا، ولا يعرض التطبيق نتائج وهمية عندما يكون الجهاز Offline.
- تنزيل حزم القرآن/الحديث/الفقه/الكتب المسموح بها سيكون قابلًا للتوسع إلى حزم محلية كبيرة.
- عند عودة الإنترنت يمكن مزامنة فهارس ومصادر جديدة.

## المنصات

- iOS/iPadOS: Capacitor + مشروع Xcode عند توليده. نشر App Store يحتاج عضوية Apple Developer وتوقيع Apple.
- Android: Capacitor + مشروع Android Studio عند توليده.
- HarmonyOS/Huawei: تبقى نسخة PWA قابلة للاستخدام، ويُجهّز مسار HarmonyOS أصلي مستقل عندما نقرر اعتماد ArkTS/DevEco Studio بدل افتراض أن Capacitor يغطي HarmonyOS.

## الأمان والحقوق

التطبيق لا يحوّل المادة `unknown` أو غير المسموح بإعادة نشرها إلى تنزيل عام. كل حزمة محتوى يجب أن تحمل provenance/rights/status قبل إدخالها إلى Offline Corpus.
