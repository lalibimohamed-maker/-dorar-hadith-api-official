# Evidence record contract

Every future unseen-world evidence record must preserve:

- source type: Quran, hadith, companion report, early scholar report, or cited scholarly work
- exact reference
- original Arabic when applicable
- evidence class
- verification state when hadith/report material is added
- no claim that book presence proves authenticity
- no generated text as evidence
- disagreement and scholarly attribution must remain visible

This seed deliberately starts with primary Quran references. Hadith and athar are added only after explicit verification and citation.
